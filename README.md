# Defenza Doors & Windows website (React + Vite)
1. Install Node.js (nodejs.org), then in this folder run:  npm install
2. Start:  npm run dev   (open the link shown)
3. Build for hosting:  npm run build   (upload the "dist" folder to Netlify or Vercel)
Edit doors in src/products.json. Add photos to public/images. Change phone/email at the top of src/App.jsx.
